# תאום דיגיטלי עירוני משותף: תקן אחד לשתי אפליקציות

**עיר אחת, מקור נתונים אחד, שפה תכנונית וחזותית אחת, ושיטת עבודה אחת.**
שתי אפליקציות שנשענות על אותו תקן:
1. **מה נבנה סביבי** (Anat1969/HITCHADSHUT): מבט כולל על ההתחדשות העירונית.
2. **תוכניות בינוי** (Anat1969/PLANS-GH): העמקה בתוכניות הבינוי, על רקע כלל ההתחדשות.

## המקור היחיד לתקן
`standard/urban-standard.mjs` במאגר הזה (גרסה **1.0.0**).
ב"מה נבנה סביבי" יש עותק זהה ב-`src/lib/urban-standard/`, ובדיקה שנכשלת אם העותק שונה:

```bash
node scripts/urban-standard/sync.mjs ../PLANS-GH --check
```

שינוי בתקן נעשה רק כאן, ואחריו מריצים את הסנכרון בלי `--check` ומעלים את `VERSION`.

## החלטות שממתינות לענת
1. **ברונזה:** ב"תוכניות בינוי" ברונזה מסמנת את פורום היועצים ואת ההתחדשות העירונית. ב"מה נבנה סביבי" היא מסמנת את תוכניות הבינוי. אותו צבע בשתי משמעויות. ההצעה: תחום תוכנית בינוי בקו שחור מקווקו בשתי האפליקציות, וברונזה רק לפורום היועצים.
2. **מסחר ומגורים ומסחר באפור:** כך במבא"ת (#adadad ו-#9c9c9c), ולכן הם קרובים לרקע האפור במצב המיקוד. הרקע נבדל בשקיפות ובחוסר רוויה. אם זה לא מספיק בעין, אפשר להחליף את גוון הרקע, אבל לא את צבע מבא"ת.
3. **מסחר בקומת הקרקע:** "מה נבנה סביבי" מציג בסיס מסחרי מתחת למגורים בכל מגרש מעורב. הזכויות מטבלה 5, אבל המיקום בקומת הקרקע הוא הנחה. לפי התקן, חלוקה לקומות רק כשהתוכנית קובעת אותה. נדרש מעבר על ההוראות של כל מגרש כזה.
4. **מיגרציה במסד** (ארבעת הסטטוסים, גרסאות ומזהים): מוכנה כהצעה ב-`data-schema.md`. לא הוחלה, כי היא משנה מסד בייצור.
