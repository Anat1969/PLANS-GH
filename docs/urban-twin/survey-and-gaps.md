# סקירה, פערים ודרך מעבר

**השורה התחתונה: מקור האמת המשותף כבר קיים, אבל הקשרים עוברים דרך עותקים סטטיים.**
שתי האפליקציות שומרות ב-ASHDODMAP (`cbhexpybdggwzyakgagd`), אבל כל אחת מחזיקה עותק של נתוני השנייה, ומעדכנים אותו ידנית.

## 1. מה יש בכל מאגר (נבדק בקוד, 25.11.2026)
| | מה נבנה סביבי (HITCHADSHUT) | תוכניות בינוי (PLANS-GH) |
|---|---|---|
| טכנולוגיה | React 19, Vite, TypeScript | קובץ `index.html` אחד וסקריפטים, בלי בנייה |
| מפה דו־ממדית | Leaflet (react-leaflet): דף הבית, ניהול | Leaflet: דף המפה (`gisMap`) |
| מפה תלת־ממדית | MapLibre GL 6: מודל העיר (`CityMap3D`), מודל תוכנית (`Plan3D`) | Three.js r147 ו-OrbitControls: מודל התוכנית (`plans-model.js`), דף הכניסה (`plans-city.js`) |
| טבלאות במסד | `plan_projects`, `plan_models`, `city_twin`, `plan_media` | `ashdod_plans`, `ashdod_muni`, `ashdod_shares`, ותיקיית `ashdod-docs` |
| נתונים סטטיים | `public/plans/*`, `public/building-plans.json` | `plans-geo.js`, `data/city.json`, `data/city-models.json`, `layers/<תיק>/`, ועכשיו `data/renewal-twin.json` |
| הרשאות | קריאה ציבורית. כתיבה בניהול (Supabase Auth) | קוד גישה לפי תפקיד. מחיקה חסומה. RLS |

## 2. זרימת הנתונים היום
1. **התחדשות לתוכניות בינוי:** קריאה חיה מ-`plan_projects` (קריאה בלבד), ועותק לגיבוי ב-`plans-geo.js`.
2. **נפחי התב"ע לתוכניות בינוי:** `plan_models` מועתק ל-`data/city.json` ול-`layers/<תיק>/renewal.json`.
3. **תוכניות בינוי להתחדשות:** `public/building-plans.json`, נבנה מ-`seed-data.json` ומ-`plans-geo.js` (`scripts/sync-building-plans.py`). מריצים ידנית.
4. **כלל ההתחדשות כרקע בתוכניות בינוי (חדש):** `data/renewal-twin.json` מ-`city_twin` (`tools/urban-standard/renewal-twin.py`).

## 4. דרך מעבר בטוחה (מדורגת, עם דרך חזרה)
1. **שלב 1, בוצע:** תקן משותף בקוד בלבד. שום שינוי במסד. החזרה: revert של הקומיט.
2. **שלב 2, מוצע:** מיגרציה **מוסיפה בלבד** (טבלאות `twin_*` חדשות, ראו `data-schema.md`). הטבלאות הקיימות לא משתנות, ושתי האפליקציות ממשיכות לעבוד גם אם ההוספה תבוטל.
3. **שלב 3:** כתיבה כפולה: כל בנייה של `plan_models` כותבת גם גרסה ל-`twin_model_versions`.
4. **שלב 4:** הקריאה עוברת מהעותקים הסטטיים לטבלאות. העותקים נשארים כגיבוי ללא רשת, עם תאריך העדכון בכרטיס.
5. **שלב 5:** מעבר עם מצלמה בין האפליקציות (`?cam=`).
