# טבלאות המעקב מהמייל מול התיקים: מה הושלם ומה סותר

**השורה התחתונה: 60 ערכים הושלמו ב-15 תוכניות. כל הסתירות נסגרו לטובת האפליקציה.**
המקור: שלוש טבלאות מעקב שאדריכלית העיר שלחה במייל (01.12.2024, 06.04.2025, ורשימת 2023-2025), וחוות הדעת בדרייב.
נקרא ב-26.11.2026, באישור ענת. נכתב לענן רק שדה ריק, וכל ערך נרשם ביומן הפעולות של התוכנית עם המקור שלו.
בקובץ הזה אין טלפונים, מיילים ושמות של יזמים: הריפו ציבורי. הפרטים נמצאים בתיקים.

## 2. כלל ההכרעה (ענת, 26.11.2026)
**מהמסמכים בדרייב ומטבלאות המעקב לוקחים רק את המספרים: אילו תוכניות קיימות.**
1. כל תוכנית שמופיעה שם אושרה, אלא אם האפליקציה אומרת אחרת.
2. **האפליקציה מעודכנת, ולכן היא גוברת בכל סתירה.** פרט ישן מטבלה (מגרשים, שם אדריכל, איש קשר) לא מחליף ערך שבאפליקציה.
3. לכן **הסתירות שנמצאו נסגרות לטובת האפליקציה, בלי החלטה:**
   1. מגרשי 1813, 1728 ו-1743.
   2. האדריכל ב-1735, ב-1750 וב-1816.
   3. איש הקשר ב-1800, וטלפון האדריכל ב-1745.
4. **הוכרעו עם ענת:**
   1. 1739: מגרש 22.
   2. 1736 היא ההגשה הקודמת של 1832.
5. **הסטטוס תוקן לפי הכלל:** 1728, 1813, 1832 ו-1830 היו "טרם עודכן", ולכולן יש חוות דעת בתיקיית הוועדה. עכשיו הן "הושלם".
