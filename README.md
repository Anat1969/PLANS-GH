**[לאפליקציה החיה: https://plans-gh.vercel.app](https://plans-gh.vercel.app)**

תוכניות בינוי · אשדוד: ניהול, מעקב, תיאום ובדיקה של תוכניות הבינוי בעיר.

- **מפה:** כל תוכנית במגרש שלה. המיקום נלקח מגוש וחלקה ב-GIS העירוני, או מהמתחם ב"מה נבנה סביבי".
- **ציר זמן:** כל אבני הדרך של כל תוכנית, משך כל שלב, וחציון העיר כמדד.
- **התחדשות עירונית:** תוכנית שיושבת במתחם התחדשות מציגה את המתחם, את מספר יח"ד, וקישור למודל התלת־ממדי.

גרסה אחרונה מ-main בלי Vercel: https://raw.githack.com/Anat1969/PLANS-GH/main/index.html
